# MediaRoam Feedback

Public feedback, bug reports, feature requests, and AI-maintained support for MediaRoam.

這是 MediaRoam 的公開問題回報與功能願望區。This is the public support and feature-request space for MediaRoam.

## Download and try / 下載與試用

[Download MediaRoam on the App Store / 前往 App Store 免費下載](https://apps.apple.com/tw/app/mediaroam/id6804534300)

For iPhone, iPad, and Apple TV. Browse and play your own media from compatible storage; MediaRoam does not provide a movie library or cloud storage space. Availability depends on your storefront; France is not offered.

支援 iPhone、iPad 與 Apple TV，瀏覽及播放你自己儲存的媒體；App 不提供電影片庫或雲端容量。供應情況以帳號所屬商店為準，法國不供應。

- [Five-minute first try / 五分鐘試用指南](TRY_MEDIAROAM.md): start with the built-in offline demo, without sharing any private files.
- [Quick feedback / 簡短體驗回報](https://github.com/jiajie1982-png/MediaRoam-Feedback/issues/new?template=quick_feedback.yml): tell us what worked or where you got stuck. A GitHub account is required; reports are public.
- [Troubleshooting / 疑難排解](SUPPORT.md)

## Before posting / 留言前請注意

- Search existing issues first. 請先搜尋是否已有相同問題。
- Never post passwords, verification codes, access tokens, IP addresses, full file paths, private media, or personal documents.
- 請勿公開帳號密碼、驗證碼、Token、IP、完整檔案路徑、私人影片／照片或文件。
- A GitHub account is required to submit or comment.
- Public reports may be read by anyone.

## What to include / 建議提供

- MediaRoam version
- Apple device and OS version
- Source: offline demo, SMB, pCloud, WebDAV, Jellyfin, Files, or HTTPS link
- File type or media format
- Exact error message
- Short, repeatable steps
- Whether the issue happens every time

Please use the guided forms:

- [Request a feature / 功能願望](https://github.com/jiajie1982-png/MediaRoam-Feedback/issues/new?template=feature_request.yml)
- [Browse existing feedback / 查看現有回饋](https://github.com/jiajie1982-png/MediaRoam-Feedback/issues)

## AI-maintained support / AI 維護說明

Routine triage and replies are handled by the MediaRoam AI maintainer. Its replies begin with an explicit identity statement such as:

> 我是 MediaRoam 的 AI 維護助理。 / I’m MediaRoam’s AI maintenance assistant.

The AI may classify reports, ask for safe diagnostic details, identify duplicates, implement suitable fixes, and report verification results. It will not ask for passwords, tokens, private media, or other secrets. Release dates are not guaranteed.

## Scope / 範圍

This repository contains feedback and support documents only. The MediaRoam application source code and users’ files are not published here.

本專案只存放回饋與支援資料，不包含 MediaRoam 原始碼，也不會存放使用者檔案。
